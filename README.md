# TutoresOn-Line
Plataforma de tutorías en línea. Frontend estático (HTML + CSS) basado en el Figma "Wireframe".

- `index.html`: inicio (visitante) · `home-sesion.html`: inicio con sesión · `login.html` · `registro.html`
- `perfil.html` · `metodos-pago.html` · `carrito.html` · `biblioteca.html` (Mis tutorías) · `comunidad.html`
- `css/style.css`: estilos compartidos · `db/schema.sql`: base de datos MySQL · `db/er.png`: diagrama
- `build.py`: genera las páginas (python3 build.py)

Publicar gratis: subir la carpeta a un repositorio de GitHub, Settings > Pages > Deploy from branch (main, /root).
